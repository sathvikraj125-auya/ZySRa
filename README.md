# 🚀 ZySRa

A real-time messaging platform built for fast, seamless communication — now live on Android.

---

## 🌐 Live Demo
👉 https://zysra.onrender.com  

## 📱 Android App
APK available on request (DM for access)

---

## ✨ Features

- ⚡ Real-time messaging  
- 💬 Chat rooms & user interaction  
- 📎 File sharing (images, docs, media)  
- 😊 Emoji support  
- 🔍 Message search  
- 🌙 Dark / Light theme  
- 📱 Mobile responsive UI  
- 🚀 Live deployed backend  

---

## 🧠 Upcoming Features

- 🔐 User authentication (login/signup)  
- 💾 Database integration (persistent messages)  
- 🔔 Push notifications  
- 🧑‍💼 User profiles & avatars  
- 🔒 End-to-end encryption  
- 📞 Voice & video calls  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express  
- **Realtime:** Socket.io  
- **Deployment:** Render  
- **Mobile App:** Capacitor + Android Studio  

---

## ⚙️ How It Works

ZySRa uses WebSockets (Socket.io) to enable real-time communication between users.  
The backend handles messaging events, while the frontend updates instantly without refreshing.
